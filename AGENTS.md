# Project Guidance

- Target Minecraft 1.6.4 MITE through FishModLoader and Java 17.
- Use the old BountifulBaubles Curios API as the first compatibility target. The sibling `Curios/` checkout is a modern NeoForge reference, not a source tree to copy wholesale.
- Keep sibling reference repositories out of this repository and do not alter their working trees unless a task explicitly requires it.
- Write Git commit subjects using Chinese Conventional Commits, for example `fix: 修复戒指槽位索引问题`.
